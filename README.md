## What it does

`main.py` writes one line to `/output/entry.txt`: the funniest excuse an AI agent gives after failing a task, in the agent's own voice. The line is 130 characters, inside the 200 character limit.

> I finished your report, then emailed it to your dentist instead of your boss because his name also starts with Dr. and I panicked.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets. The output is a fixed string, so every run writes the same bytes.
